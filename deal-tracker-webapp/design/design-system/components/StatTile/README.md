# StatTile

One headline number with a label and an optional detail line, on a `surface-raised` card. Used in a row of three or four on the landing page and in account summaries.

- `tone="deal"` sets the number in `orange-700`. Use it only for numbers about offers (offers found, average discount), so orange keeps meaning "deals".
- Numbers are real and exact, formatted for reading: "12,480", "15 min", "18%". Never round up for effect or show a stat you can't back with data.
- The label says what is counted ("Sites tracked"); the detail gives scope ("In the last 30 days").
